# GeoAI Mineral Labs

A reproducible learning and experimentation repository focused on
machine learning, deep learning, spatial data science and GeoAI
applications for mineral exploration.

## Objectives

This repository documents a progressive laboratory series covering:

- Python geospatial data science
- spatial statistics
- spatial cross-validation
- mineral prospectivity mapping
- geochemical compositional data analysis
- machine learning
- deep learning
- remote sensing
- explainable AI
- uncertainty quantification
- reproducible ML workflows

## Engineering principles

- Reproducibility first
- Spatially aware validation
- No credentials or private data in Git
- Simple baselines before complex models
- Geological interpretation alongside predictive performance
- Experiment tracking and traceability
